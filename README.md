## Chi siamo

Strada Pratica nasce da chi lavora su strada: un autista ADR che vuole togliere burocrazia alle piccole imprese di autotrasporto.
Siamo in fase di ricerca di mercato: non offriamo ancora servizi a pagamento né servizi regolamentati.
